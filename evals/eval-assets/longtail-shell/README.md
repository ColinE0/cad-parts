# Longtail top shell

The body shell over the Longtail robot's chassis. It screws to the base plate through four corner
bosses (M3 self-tappers up through the plate). `chassis_ref.py` holds the chassis parts the shell
is fit-checked against, measured off the robot on 2026-10-28.

| Version | What changed | Status |
|---|---|---|
| v5 | first shell with the battery hatch | printed 2026-10-12; tyres rubbed the arches (1.5 mm clearance) |
| v6 | arch clearance 1.5 -> 3 mm, rear wing added | printed 2026-10-20; wing struts snapped in a crash |
| v7 | wing struts 4 -> 6 mm square, wing chord 16 -> 20 | printed 2026-11-02, fitted |

v5 and v6 are not kept here.

**The one to print: v7**, `stl/longtail_shell_v7.stl`, written by `longtail_shell_v7.py`.
Printed upright, open bottom on the bed, PLA, 0.2 mm layers.
